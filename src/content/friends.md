## 关于这一页

这里的每一张卡片都指向一个真实在写、在维护的站点。卡片顺序在每次构建时随机打乱，所以没有「排前面更靠前」这回事——顺序只代表随机。

- 卡片上的**头像**来自 `imgurl` 字段；
- **站名**来自 `title`；
- **一句话介绍**来自 `desc`；
- 点击卡片会打开 `siteurl`；
- 卡片下方最多显示两个 `tags`，更多的会折叠成 `+N`。

## 申请方式

把下面这些信息发给我即可，标题写「友链申请」：

```
站点名称：
站点地址：
站点简介（一句话，30 字以内）：
头像地址：
站点标签（1~3 个）：
```

- **邮箱**：`hello@example.com`
- **或者在代码仓库开一个 issue**，把这些信息贴在正文里。

收到之后我会先访问一遍你的站点。确认可以访问、内容持续更新、且与本站调性大致相符，就会加进来，通常一周内处理。

## 数据格式

友链数据存放在 `src/content/friends/` 目录下，**一个 JSON 文件对应一条友链**，文件名（不含扩展名）就是这条友链的 id：

```json
{
    "title": "拾光记",
    "imgurl": "/assets/images/placeholders/a-01.svg",
    "desc": "记录手艺、旧物与日常的中文博客，更新慢但每篇都很耐读。",
    "siteurl": "https://example.com/shiguang-ji",
    "tags": ["博客", "随笔"]
}
```

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `title` | 字符串 | 必填 | 站点名称，显示在卡片标题位置 |
| `imgurl` | 字符串 | 必填 | 头像图片地址；可以是以 `/` 开头的站内路径，也可以是完整的 `https://` 外链 |
| `desc` | 字符串 | 必填 | 一句话简介，卡片上只显示一行，建议 30 字以内 |
| `siteurl` | 字符串 | 必填 | 站点地址，卡片点击后跳转到这里，会在新标签页打开 |
| `tags` | 字符串数组 | 可选 | 站点标签，卡片上最多显示 2 个，其余折叠为 `+N` |

:::note
JSON 文件里**不能写注释、也不能有多余的逗号**，否则构建会直接报错。文件名请使用英文小写加连字符（例如 `shiguang-ji.json`），避免网址与文件系统编码带来的麻烦。
:::

## 头像怎么放

两种方式都可以：

1. **外链**：直接填图床地址，例如 `https://example.com/avatar.png`。改动方便，但对方图床挂掉时卡片头像会一起变成空白。
2. **放本地**：把图片放进 `public/assets/images/` 下的位置，然后写成 `/assets/images/...` 开头的路径。稳定，但需要把图片提交进仓库。

建议头像用正方形图片，尺寸 256×256 左右就够——卡片上的显示区域是圆的，太宽或太长的图会被裁掉。

## 一些约定

- 站点需要**能长期访问**：临时搭建、长期打不开或者整站跳转的地址不适合放进友链；
- 内容以**个人创作**为主：纯采集站、聚合站、营销落地页一般不会收录；
- 想撤回随时说：你自己的站点改版、关站或者不想被列在这里了，告诉我一声就会移除；
- 我也会定期清理：连续几个月无法访问、或者内容已清空的站点，会先从这里移除，之后你想回来再申请一次就好。
