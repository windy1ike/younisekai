## 这是什么

**younisekai 是一个「内容即文件」的静态博客模板。**

它把写博客需要的所有东西都准备好了——文章、项目、技能、历程、日记、相册、友链，每一类内容都对应一个目录、一套字段和一个自动生成的页面。你只需要写 Markdown 和 JSON，剩下的排版、路由、搜索索引、RSS 都由构建过程完成，产出是一堆可以直接托管的静态文件。

它同时支持后台管理：接上内容管理系统后，可以在浏览器里新建文章、修改数据、上传图片，改动以提交的形式回到仓库，不需要在本机装任何编辑器。

## 特性清单

- **内容集合驱动**：文章用 Markdown，其余数据用 JSON，字段由 schema 统一约束，写错了会在构建时直接报出来；
- **嵌套分类与标签云**：分类支持任意层级（例如「技术笔记 / 前端」），标签自动汇总成云并支持筛选；
- **完整的内容页面**：归档、项目、技能、历程、日记、相册、友链各有独立页面与统计信息；
- **全站静态搜索**：构建时生成 Pagefind 索引，搜索完全在浏览器里完成，不需要任何后端；
- **文章加密**：按篇设置密码，正文以密文形式下发，在浏览器端解密展开；
- **复制保护**：四项开关独立控制选中、剪贴板、右键与开发者工具；
- **排版扩展**：提示框、GitHub 仓库卡片、Mermaid 图表、KaTeX 数学公式、代码折叠与行高亮开箱可用；
- **主题可配置**：站点信息、主题色相、壁纸模式、导航菜单、侧栏挂件、评论与统计全部集中在一个 YAML 里；
- **多语言与暗色模式**：内置浅色/深色/跟随系统三种模式，支持客户端翻译；
- **零供应商锁定**：纯静态输出，可以部署到任何支持静态托管的平台，也可以自建 Docker 镜像。

## 技术栈

| 层次 | 选型 | 用途 |
| --- | --- | --- |
| 构建 | [Astro](https://astro.build/) | 页面路由、内容集合、图片与资源管线 |
| 样式 | Tailwind CSS | 版式、暗色模式、响应式断点 |
| 交互 | Svelte | 搜索框、目录树、音乐播放器、设置面板 |
| 语言 | TypeScript | 工具函数、类型约束与数据校验 |
| 搜索 | [Pagefind](https://pagefind.app/) | 构建期生成静态索引 |
| 图表 | Mermaid | 流程图、时序图、状态图、甘特图、饼图 |
| 公式 | KaTeX | 行内与独立数学公式 |
| 代码 | Expressive Code | 代码高亮、行号、折叠与语言角标 |

## 目录结构

```
项目根目录/
├── public/                      # 直接进入产物的静态资源
├── scripts/                     # 构建脚本、图标生成、新建文章
├── src/
│   ├── components/              # 组件
│   ├── content/                 # 全部内容与数据
│   │   ├── posts/               # 文章（Markdown，支持子目录）
│   │   ├── projects/            # 项目（JSON + 封面）
│   │   ├── skills/              # 技能（JSON）
│   │   ├── timeline/            # 历程（JSON）
│   │   ├── diary/               # 日记（JSON + 配图）
│   │   ├── albums/              # 相册（JSON + 图片）
│   │   ├── friends/             # 友链（JSON）
│   │   ├── about.md             # 本页内容
│   │   └── friends.md           # 友链页说明
│   ├── layouts/                 # 页面骨架
│   ├── pages/                   # 路由：文件即页面
│   ├── styles/                  # 主题变量与样式
│   └── utils/                   # 内容读取与整理
├── astro.config.mjs             # 构建与插件配置
└── younisekai.config.yaml       # 站点、主题、侧栏、评论等总配置
```
