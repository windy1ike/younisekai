## 这是什么

**这是YouniSekai， 是 KazeYouni 的个人博客。**

**是我用以记录，保存所思所想的地方**

其实，很久以前我就想做一个这样的容器了，但是太懒了我。

正好借着发展迅速的Agent实现我的想法。

这个站点用 [Astro](https://astro.build/) 做构建，用 Tailwind CSS 排版，用 Svelte 写交互组件，后台是 Sveltia CMS，纯静态文件，没有数据库，也没有运行时服务端。

- **内容是文件**：文章是 Markdown，项目、技能、历程、日记、相册、友链是 JSON，全部放在 `src/content/` 里，可以用 Git 管理、可以随时整体迁移；
- **自带后台**：接上内容管理系统之后，可以在浏览器里直接写文章、改数据，不用在本机装编辑器；
- **一些细节**：暗色模式、全站搜索、目录树、代码高亮与折叠、文章加密、复制保护、阅读进度与字数统计；
- **零供应商锁定**：搜索索引在构建时生成，加密在浏览器端完成，评论等外部服务默认关闭、需要时再打开，产物可以部署到任何静态托管上。

## 技术栈

| 层次 | 选型 | 用途 |
| --- | --- | --- |
| 构建 | [Astro](https://astro.build/) | 页面路由、内容集合、图片与资源管线 |
| 样式 | Tailwind CSS | 版式、暗色模式、响应式断点 |
| 交互 | Svelte | 搜索框、目录树、设置面板等交互组件 |
| 后台 | Sveltia CMS | 浏览器里写文章与改数据，改动以 commit 回到仓库 |
| 语言 | TypeScript | 工具函数、类型约束与数据校验 |
| 搜索 | [Pagefind](https://pagefind.app/) | 构建期生成静态索引 |
| 图表 | Mermaid | 流程图、时序图、状态图、甘特图、饼图 |
| 公式 | KaTeX | 行内与独立数学公式 |
| 代码 | Expressive Code | 代码高亮、行号、折叠与语言角标 |
